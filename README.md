# One Ticker, Every Desk

A single-file interactive presentation by Katrina Li.

A one-shot equity modeling harness that runs a five-day stock ramp in under 20 minutes, the
risk-weighted model router ("the Allocator") that makes it cheap enough to run on every desk,
and how the same method carries across investment banking, private markets, and FP&A and the
back office.

**Live:** https://katrinalicolumbia-eng.github.io/one-ticker-every-desk/

Everything is in `index.html` — no build step, no dependencies.
